# Меридиан

Интерактивный атлас мира. Карта стран, пять показателей и карточка выбранной страны: ранг, доля от максимума и сравнение с медианой.

Показатели: долголетие, доход на человека, доля возобновляемой энергии, городское население, доступ в интернет.

## Стек

React 19, TanStack Start, Tailwind CSS 4, d3-geo, Natural Earth (`world-atlas`).

## Локально

```bash
npm install
npm run dev
```

Приложение слушает порт 8080.

```bash
npm run typecheck
npm test
npm run build
```

## Публикация

Сборка рассчитана на Vercel и Nitro: `npm run build` кладёт результат в `.vercel/output`. В [vercel.json](vercel.json) отключён автодетект Vite, чтобы деплой не искал статический `dist` и не отдавал пустую страницу.
